# app_with_riverpod

A simple Flutter application that displays a list of countries with details like name, capital, and region.  
Useful for learning Flutter basics like ListView, API calls, and state management.

## 🚀 Features
- Display list of countries
- Show country details (Capital, Region, Population, etc.)
- Clean and minimal UI

## 🛠️ Installation

### Prerequisites
- Flutter SDK installed
- Dart SDK installed
- Android Studio or VS Code (recommended)

### Steps to Run
```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
cd YOUR-REPO-NAME
flutter pub get
